# Smart Silent Distress Monitoring System

## Team Name
Tech-Blasters

## Problem Statement
Elderly people and individuals who live alone often face serious risks such as sudden falls, medical emergencies, weakness, dizziness, or accidents inside the home. In many cases, they may be unable to reach a phone, call for help, or communicate their condition in time. Traditional emergency support systems mostly depend on manual calling or nearby assistance, which may not always be available. Delayed response during such situations can lead to severe health complications and increased danger. Therefore, there is a growing need for an intelligent monitoring system that can silently detect emergencies and immediately alert caregivers or family members.

## Our Solution
The Smart Silent Distress Monitoring System is an IoT-based safety device designed to protect elderly people and those living alone. The system continuously monitors emergency situations such as fall detection, prolonged inactivity, or manual SOS button activation. When a distress event is identified, the device automatically sends an alert message along with live location details to family members, caretakers, or emergency contacts using GSM/WiFi communication. Local alerts such as buzzer and LED indications can also be activated for nearby assistance. This solution provides faster response, improved safety, and peace of mind for both users and their families.

## Features
- Automatic Fall Detection
- Prolonged Inactivity Detection
- Instant Emergency Alert Message
- Live GPS Location Sharing
- Buzzer / LED Local Alert
- Real-Time Safety Monitoring
- Fast Assistance Without Phone Usage

## Components Used
- ESP32 / Arduino
- Accelerometer Sensor
- GPS Module
- GSM / WiFi Module
- Push Button Switch
- Buzzer
- LED
